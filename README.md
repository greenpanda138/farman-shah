# Farman Shah — Portfolio

Freelance web developer portfolio. Editorial, work-led, hand-coded — no templates, no page builders.

**Live:** https://greenpanda138.github.io/farman-shah/

## Stack

- Plain HTML, CSS, and JavaScript — no framework
- Vanilla Three.js + GSAP for one scroll-choreographed 3D moment (the site deconstructed into design / code / content layers)
- Fraunces typeface, warm paper palette

## Structure

- `index.html` — the whole site, one page
- `assets/css/style.css` — editorial styles, one ground / one ink / one accent
- `assets/js/main.js` — entrance + lazy 3D boot
- `assets/js/three-process.js` — the 3D layers scene (demand-rendered, DPR capped at 2, static fallback for reduced motion / mobile / no WebGL)
- `assets/js/` — vendored three.module.min.js, gsap.min.js, ScrollTrigger.min.js
- `assets/img/avatar.png` — portrait
